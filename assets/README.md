# assets/

앱에 넣는 정적 파일. `fonts/`에 Pretendard(본문)와 SUIT(금액) OTF가 있습니다. 전체 벤더 덤프(`Pretendard-1.3.9/`, `SUIT-otf/`)는 git에 올리지 않습니다.

`images/`의 Subly 브랜드 자산:

- `brand-mark.png`: 투명 배경 심볼 원본
- `logo-horizontal.png`: 심볼과 영문 워드마크 조합
- `icon.png`: iOS 및 기본 앱 아이콘
- `android-icon-foreground.png`, `android-icon-monochrome.png`: Android 적응형·테마 아이콘
- `splash-icon.png`, `favicon.png`: 시작 화면과 웹 파비콘

웹 폰트는 [`web/public/fonts/`](../web/public/fonts/)입니다.
