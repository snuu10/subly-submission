## 반영 방법

### 이 파일 수정 후, 기존 공지 내용을 업데이트하려면:

```bash
cd /Users/chan/Developer/seongnam-ai-camp/projects/subly
source <(cat .env web/.env 2>/dev/null | grep -E "SUPABASE")

curl -s -X PATCH \
  -H "apikey: ${SUPABASE_SERVICE_ROLE_KEY}" \
  -H "authorization: Bearer ${SUPABASE_SERVICE_ROLE_KEY}" \
  -H "content-type: application/json" \
  -H "prefer: return=representation" \
  "${EXPO_PUBLIC_SUPABASE_URL}/rest/v1/announcements?id=eq.78392df7-6e2e-45ae-93a1-d6ed3374e920" \
  -d '{
    "title": "여기에 수정한 title",
    "body": "여기에 수정한 body",
    "tag": "업데이트"
  }'
```

### 새 공지사항으로 등록하려면 (INSERT):

```bash
curl -s -X POST \
  -H "apikey: ${SUPABASE_SERVICE_ROLE_KEY}" \
  -H "authorization: Bearer ${SUPABASE_SERVICE_ROLE_KEY}" \
  -H "content-type: application/json" \
  -H "prefer: return=representation" \
  "${EXPO_PUBLIC_SUPABASE_URL}/rest/v1/announcements" \
  -d '{
    "title": "새 제목",
    "body": "새 본문",
    "tag": "업데이트"
  }'
```
