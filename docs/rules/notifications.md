# 결제일 알림

갱신: 2026-09-14

## 공통

- 활성 구독의 결제일을 기준으로 **D-3, D-1 알림**을 제공한다.
- D-Day에는 앱·웹에서 `오늘 갱신 예정`으로 표시한다.
- 모든 정기 구독은 자동 갱신으로 가정하며 매달 결제 여부를 묻는 D+1 푸시는 보내지 않는다.
- 알림 문구는 실제 결제를 단정하지 않고 `결제 예정` 또는 `갱신 예정`이라고 표현한다.

## 웹

- 헤더의 종 모양 아이콘에 확인하지 않은 알림 수를 빨간 숫자 배지로 표시한다.
- 종 아이콘을 누르면 전체 알림을 확인할 수 있어야 한다.

## 앱

- D-3, D-1 결제일 알림을 푸시 알림으로 제공한다.
- 설정에서 전체 결제 알림, D-3, D-1, 모든 기기 푸시, 현재 기기 푸시를 각각 켜고 끌 수 있다.
- 현재 기기 푸시 OFF는 다른 기기와 웹·앱 알림함에 영향을 주지 않는다.
- 매너모드는 사용자가 정한 시간에 알림과 배지는 표시하되 소리와 진동만 끈다.
- 매너모드 기본 시간은 오후 9시부터 오전 8시까지다.
- 알림 설정을 끈 뒤에는 이전 실패 건의 재시도로 푸시가 발송되지 않아야 한다.
