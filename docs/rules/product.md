# 제품 범위

갱신: 2026-09-05 (과거 발화 기록)

## 한 줄

계좌 연동 없이 30초 만에 등록하고, 안 쓰는 구독을 스스로 찾아주는 초경량 구독 관리.

## 고정 규칙

- **마이데이터·계좌·카드 연동 없이** 수동 등록만으로 동작한다.
- 온보딩은 가볍게, 금융 정보 접근 권한은 필요하지 않다.
- 타깃: 구독 5~15개를 가진 20~30대 자취 직장인·프리랜서.
- **안드로이드 출시를 우선**하되 향후 iPhone 앱도 제공할 크로스플랫폼 제품으로 설계한다.
- 플랫폼 공통 기능과 용어는 Android·iOS에서 동일하게 유지하고, 스토어 연결과 빌드 번호처럼 필요한 부분만 플랫폼별로 나눈다.
- 현재 Android 앱은 Google Play 심사 전이며 정식 출시되지 않았다. 출시 완료를 전제로 한 문구나 동작을 노출하지 않는다.
- 설정의 앱 정보에는 공통 앱 버전과 플랫폼별 빌드 번호를 표시한다. Android는 `versionCode`, iOS는 `buildNumber`를 사용한다.
