# 웹 사이드바

갱신: 2026-09-05

## 대시보드

- 제목 옆에 **구독 추가**, **결제수단 추가** 바로가기를 둔다.
- 구독 목록 위젯은 한 칸으로 줄이고, 옆에 **결제수단 목록** 위젯을 둔다.

출처: 2026-09-05 「차니의 대시보드 옆에 구독·결제수단 추가, 구독리스트 줄이고 결제수단 목록 위젯」

## 사이드바

갱신: 2026-09-14

대시보드 그리드는 유지하고, 왼쪽 트리로 화면을 고른다.

```
구독
├─ 현황
│  ├─ 결제 현황
│  ├─ 결제 예정
│  └─ 사용 기록
└─ 관리
   ├─ 구독 목록
   ├─ 구독 추가
   └─ 카테고리

자산
└─ 결제수단
   ├─ 은행
   └─ 카드

설정
```

- 은행·카드는 구독 아래가 아니라 **자산 → 결제수단** 아래다.
- **설정**은 트리 아래, 비밀번호 변경(이메일 계정만)을 둔다.
- 결제 현황의 숫자는 [spend-metrics.md](./spend-metrics.md)의 **이번 달 예상 지출액**이다.
- 웹에서 로그인할 때 사이드바는 화면 크기와 관계없이 닫힌 상태로 시작한다.
- 화면 크기가 데스크톱으로 바뀌어도 사이드바를 자동으로 열지 않으며, 사용자가 메뉴 버튼으로 직접 연다.

출처: 2026-09-01 트리 재구성, 2026-09-05 자산/현황 재정리, 2026-09-14 로그인 기본 닫힘.
