# 공지사항(업데이트 로그)

배포될 때마다 웹에 간단히 남기는 업데이트 안내. 사용자가 첨부한 쿠팡 WING/OpsNow 스크린샷을 참고해 구현했다.

- 등록: 작성 UI 없음. `public.announcements` 테이블에 직접 SQL로 삽입한다(title, body, tag, published_at).
- 노출: 헤더의 별도 아이콘(공지사항 전용, 결제 알림 종과는 다른 아이콘) → 드롭다운에 최근 2개 미리보기 + 전체보기 → 목록 페이지(페이지네이션) → 항목 클릭 시 상세 모달.
- 읽음 처리는 계정별로 서버(`public.announcement_reads.last_read_at`)에 저장해 기기·브라우저가 달라도 유지된다.
- 배지 카운트 기준(사용자 아이디어): "최근 7일 이내 발행 + 아직 안 읽음" 인 것만 센다. 7일보다 오래된 공지는 안 읽었어도 배지에 안 잡히고, 목록에서는 계속 보인다.
