# 카테고리 이름

갱신: 2026-09-14

- 앱·웹·비서는 카테고리 이름에 같은 정규화 규칙을 사용한다.
- 저장 전 Unicode NFKC 정규화, 앞뒤 공백 제거, 연속 공백 축약을 적용한다.
- 카테고리 이름에는 한글, 영문, 숫자와 공백만 사용할 수 있다.
- 카테고리 이름은 1~20자로 제한한다.
- 공백·대소문자 차이만 있는 이름은 같은 카테고리로 취급한다.
- `디즈니+`, `네이버+`처럼 서비스의 고유한 표시 이름에는 이 제한을 적용하지 않는다.
- 카테고리 직접 조회에는 임베딩보다 정규화된 이름 일치를 우선한다.
