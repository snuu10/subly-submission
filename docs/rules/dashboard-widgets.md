# 웹 대시보드 위젯

갱신: 2026-09-14

## 배치

- 웹 대시보드 위젯은 각 카드의 전용 핸들을 드래그해 좌우·상하로 자유롭게 배치한다.
- 저장된 배열 순서대로 DOM을 렌더링하여 시각 순서와 키보드·스크린리더 탐색 순서를 일치시킨다.
- 반응형 화면에서는 같은 순서를 유지한 채 1열·2열·3열로 재배치한다.
- 브라우저 전체 화면의 데스크톱 대시보드는 OpsNow처럼 3열을 사용한다. 현재 8개 위젯을 모두 표시하면 3·3·2의 3행이 된다.
- 대시보드 위젯 슬롯은 콘텐츠 양과 관계없이 동일한 크기로 고정한다.
- 고정된 카드보다 정보가 많으면 카드 전체를 늘리지 않고 제목·조작부 아래의 본문 영역에 세로 스크롤을 제공한다.
- 드래그 중 카드 크기는 바꾸지 않고 위치만 짧게 보간하여 OpsNow처럼 큰 확대·축소 없이 이동한다.
- 운영체제의 모션 축소 설정이 켜져 있으면 정렬 전환 애니메이션을 제거한다.

## 표시 설정

- 인사이트, 나우 로그, 카테고리, 월평균 구독 지출액은 삭제할 수 없는 기본 위젯이다.
- 다가오는 결제, 구독 구성, 구독 목록, 결제수단 목록은 카드 메뉴에서 삭제할 수 있다.
- 삭제한 위젯은 **+ 위젯 추가**에서 다시 선택할 수 있다.
- 삭제한 위젯도 전체 순서 안의 위치를 유지하며, 다시 추가하면 기존 위치 문맥으로 돌아온다.
- 삭제 완료 알림은 다음 문구를 사용한다.

  ```text
  위젯 삭제
  [{위젯 이름}] 위젯이 삭제되었습니다.
  [+ 위젯 추가] 버튼을 클릭해 위젯을 다시 추가하실 수 있습니다.
  ```

## 초기화

- 기존 **기본 배치** 명칭은 **위젯 초기화**로 변경한다.
- 위젯 초기화는 기본 4개 위젯만 표시하고 전체 순서를 기본값으로 복원한다.
- 초기화 전에 아래 문구의 확인 창을 표시한다.

  ```text
  위젯 초기화
  대시보드의 위젯과 레이아웃을 기본 상태로 초기화하시겠습니까?
  초기화하시면 설정하신 내용이 사라집니다.
  ```

## 저장 범위

- 순서와 표시 설정은 브라우저 로컬이 아니라 Supabase에 사용자 계정별로 저장한다.
- 이번 구현 범위는 웹이며 앱 대시보드에는 적용하지 않는다.
- 새 위젯이 배포되면 기존 사용자 저장값 뒤에 자동으로 보충한다.
