# 구독 목록 카테고리 순서

갱신: 2026-09-05 (과거 발화 기록)

앱·웹 공통 사항으로 시작했지만, 저장 방식은 아래가 최종이다.

## 배치

- 사용자가 칩 순서를 자유롭게 바꾼다. 예: `전체 · 음악 · 업무` → `전체 · OTT · 업무`.
- **기타는 맨 마지막 고정.**
- **전체는 맨 앞.**

출처: 2026-09-02 「구독 목록 카테고리 배치를 사용자가 커스텀」

## 저장

- 처음에는 앱·웹 연동이 필요 없다고 했다.
- 이후: 다른 PC·기기에서 초기화되지 않게 **웹용 순서 / 앱용 순서를 DB에 따로** 둔다.
- **AI 비서 기능에 영향이 가면 안 된다.**

출처: 2026-09-02 「연동이 필요 없습니다」 → 2026-09-03 「DB에 웹 전용 순서용, 앱용 순서도 DB」

## 앱 화면

- **설정 > 카테고리 관리**에 이미 있는 기능은 **건드리지 않고**, 같은 화면에 순서 배치만 추가한다.
- 드래그·슬라이드 애니메이션으로 옮긴다.
- 실수 방지를 위해 **잠금(자물쇠)** 이 있다. 기본은 잠금.
- 구독 **목록**에 있던 잠금·순서 배치는 삭제해도 된다.

출처: 2026-09-03.
