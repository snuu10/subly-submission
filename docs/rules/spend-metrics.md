# 월평균 구독 지출액 / 예상 지출액

앱·웹·비서 공통. 계좌·카드 연동이 없으므로 핵심은 **매달 유지되는 비용**과
**등록된 일정으로 예상되는 결제액**을 분리하는 것이다.

갱신: 2026-09-05

## 두 지표

| 지표 | 의미 | 일회성 결제 |
|---|---|---|
| **월평균 구독 지출액** | 정기 구독 비용을 월 단위로 환산한 금액 | 제외 (0원) |
| **이번 달 예상 지출액** | 등록된 일정상 이번 달에 결제될 전체 금액 | 포함 |
| **다음 달 예상 지출액** | 등록된 일정상 다음 달에 결제될 전체 금액 | 포함 |
| **확인된 결제액** | 영수증 또는 사용자 입력으로 확인한 금액 | 포함 |

예시: 정기 구독료 30,000원 + 일회성 10,000원

| 지표 | 금액 |
|---|---|
| 월평균 구독 지출액 | 30,000원 |
| 이번 달 예상 지출액 | 40,000원 (정기 30,000 + 일회성 10,000) |

## 계산

- **연간 구독**: 월평균 = 연간 금액 ÷ 12. 결제 예정 월에는 연간 금액 전체를 예상 지출액에 반영.
- **일회성 결제**: 월평균 = 0원. 등록된 결제 월에만 전체 금액을 예상 지출액에 반영.
- **환불**: 확인된 경우에만 확인된 결제액에서 차감하고 환불로 별도 표시.
- **예정일 전·후**: 자동 갱신 가정이므로 이번 달 예상 지출액에는 모두 포함한다.

## 표현

- 비서의 「이번 달 얼마」 → **월평균 구독 지출액**을 먼저 답하고 이번 달 예상 지출액도 함께 안내
- 웹의 「결제 현황」 지표 → **이번 달 예상 지출액**
- 결제 현황 상세 → **정기 결제** / **일회성 결제**로 구분

안내 문구:

> 월평균 구독 지출액은 연간 구독료를 12개월로 나눈 금액을 포함합니다. 예상 지출액은 등록된 결제 일정 기준이며 실제 결제 내역이 아닙니다.
